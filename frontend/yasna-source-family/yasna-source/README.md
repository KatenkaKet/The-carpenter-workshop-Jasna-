# Ясна — прототип системы записи

Кабинеты мастера и родителя для детской столярной мастерской: тарифы, оплата,
запись без ожидания подтверждения, чеки, история посещений и оплат.

Демонстрация: https://serbaulia5.chatium.ru/yasna

## Что внутри

- Кабинет мастера: расписание, день, журнал, абонементы, клиенты, финансы,
  список записей из кабинета родителя.
- Кабинет родителя: вход по готовой ссылке от мастерской, календарь, тарифы,
  оплата и запись в одном окне, история посещений и оплат.
- Общие компоненты и демо-данные в `components/` и `shared/`.
- Подробности, маршруты и ограничения — в `.CHATIUM-LLM.md`.

## Как открыть кабинет родителя

В кабинете мастера откройте «Клиенты» → семью → «Ссылка для родителя».
Мастерская отправляет эту ссылку родителю. Родитель просто открывает её — без
ввода токена, кода или пароля. Для демо на экране входа есть «Демо-доступ».

Родитель выбирает занятие и нажимает «Записаться»: если тариф уже оплачен,
запись создаётся сразу; если нет — выбирает 1 посещение или абонемент, переходит
на страницу оплаты и нажимает «Оплатить». После оплаты запись создаётся сразу.
Мастерское подтверждение не требуется.

## Как это запускается

Это воркспейс аккаунта Chatium, а не самостоятельный Node.js-сервер. Chatium
собирает и публикует его после `git push` в ветку `main`; отдельная сборка и
локальный сервер не нужны.

Проверка типов:

```sh
chatium typecheck yasna
```

## Демо-данные

Данные вымышленные. Изменения сохраняются в браузере в
`localStorage["yasna.demo.v7"]`, сброс — ссылка «Сбросить демо-данные» в меню
мастера. Чеки — реальные файлы в защищённом FileService.

## Ограничения

Нет настоящего бэкенда, cookie-сессий и ЮKassa: оплата и вход демонстрационные.
Маршрут выдачи чека пока не проверяет роль. Подробнее — в `.CHATIUM-LLM.md`.
