## Как получить ID через ваши запросы

1. Войти мастером.
2. `GET /api/v1/master/families?search=ДЕМО` — ID семей.
3. `GET /api/v1/master/families/:id` — дети семьи и их ID.
4. `GET /api/v1/master/groups?search=ДЕМО` — группы.
5. `GET /api/v1/master/lessons` — занятия.
6. `GET /api/v1/master/payments?family_id=:id` — оплаты и прикреплённые файлы.
7. `GET /api/v1/master/children/:id/subscriptions` — абонементы.

Для входа родителем выдайте новую ссылку через `POST /api/v1/master/families/:id/access-links` с будущим `expires_at`, затем используйте `POST /api/v1/auth/access-link/exchange`. Добавленные для примера ссылки и сессии отозваны: готовых открытых секретов доступа в скрипте нет. Текущая учётная запись мастера не изменена.

## Повторное заполнение

Из корня проекта:

```sh
./backend/scripts/seed-demo.sh
```

Скрипт выполняется одной транзакцией с блокировкой изменений. Повторный запуск не создаёт дубликаты: проверяется маркер `jasna-demo-seed-v1` в аудите.

Записи добавлены во все 22 прикладные таблицы. `schema_migrations` не заполняется вымышленными строками: это журнал настоящих миграций, от которого зависит запуск сервера.
