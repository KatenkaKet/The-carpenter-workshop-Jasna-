# Jasna

- `backend/` — будущий бэкенд на Go.
- `frontend/` — будущий фронтенд; стек пока не выбран.
- `compose.yaml` — PostgreSQL и заготовки двух сервисов приложения.

## Запуск

Пока можно запустить только базу данных:

```sh
docker compose up -d db
```

После добавления `backend/Dockerfile` и `frontend/Dockerfile` весь проект запускается командой:

```sh
docker compose up -d --build
```

Бэкенд должен читать переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` и слушать `0.0.0.0:8080`. Для фронтенда временно указан порт `3000`; его нужно согласовать с выбранным стеком. Из браузера бэкенд будет доступен по адресу `http://localhost:8080`.

База доступна внутри сети Compose по адресу `db:5432`. Данные сохраняются в томе `postgres_data`. Значения подключения по умолчанию предназначены для локальной разработки; переопределить их можно переменными `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` в окружении или файле `.env`.
