# Отчёт о продолжении доработки — 15 ноября 2026

## Реализовано в этом продолжении

- Удалены группы из интерфейса тарифов, формы создания и карточек учёта абонементов. Новые покупки через интерфейс универсальны; данные расписания и условия прежних оплаченных абонементов сохранены.
- Настройки списаний/отмен/переносов сохраняются общими для мастерской, без выбора группы. Настройка 0 часов проверена на уже оформленной записи.
- Добавлена явная запись до покупки абонемента. После оплаты подходящие записи получают резерв в той же транзакции. Резерв не превышает оплаченный остаток.
- Добавлена отключаемая тестовая оплата без провайдера, с повторным использованием существующих финансовых операций и защитой от повторного зачисления. Родитель видит тестовый характер операции.
- Добавлены кнопки CSV для клиентов, посещений и оплат. Период выгрузки теперь необязателен.
- В счётчиках отображается название тарифа, предварительные записи отмечены ожиданием покупки. Тестовый платёж можно аннулировать с сохранением истории.

Ранее реализованные произвольное время/длительность, отработка, отсутствие оценок, вертикальные списки, ручные оплаты, резервирование, отмены, чеки, отзыв ссылок и фильтрация уведомлений сохранены и повторно проверены в соответствующих тестах.

## API

Новые: `GET /public/payment-options`, `POST /payments/test-confirm`, `GET/PUT /master/booking-policy`.

Изменённые: создание тарифов допускает отсутствие `group_id`; создание записи принимает `awaiting_payment`; успешная оплата распределяет резерв по предварительным записям; списки абонементов включают `plan_title`; аннулирование допускает `method=test`; CSV посещений/оплат можно получить без дат. Все адреса относительно `/api/v1`.

Полные тела запросов, права и коды ошибок: [endpoint.md](../endpoint.md).

## Миграция

Добавлена `003_universal_plans.sql`; запускается автоматически после 001–002, в транзакции под блокировкой миграций. Снимает обязательность групп для тарифов/абонементов/счетов, переводит текущие планы в универсальные для будущих покупок, расширяет допустимые способы оплаты и учёта записи, добавляет единственную общую настройку правил. Существующие группы, дети, оплаты, посещения, счета и оплаченные абонементы не удаляются.

## Оставшиеся продуктовые решения

- Настоящая онлайн-оплата и возвраты требуют подключённого провайдера; текущая заглушка явно тестовая.
- Существующие оплаченные абонементы сохраняют старую привязку к группе. Их перевод в универсальные требует отдельного решения, поскольку меняет ранее оплаченные условия.
- Срок удержания места для предварительной неоплаченной записи не вводился: автоматическое снятие такой записи требует согласованных правил.

Инструкция показа и выгрузки: [demo-and-export.md](demo-and-export.md).
