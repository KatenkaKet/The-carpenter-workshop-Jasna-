# Ясна — исходники прототипа

Кабинет мастера детской столярной мастерской: расписание, журнал, абонементы,
клиенты и финансы с чеками.

Публичная демонстрация: https://serbaulia5.chatium.ru/yasna

## Что внутри

- `index.tsx`, `day.tsx`, `journal.tsx`, `subscriptions.tsx`, `clients.tsx`,
  `finance.tsx` — страницы и маршруты.
- `receipt.ts` — выдача временной ссылки на защищённый файл чека.
- `screens/` — экраны на Vue.
- `components/` — общий каркас, календарь, шторки, оценки.
- `shared/demo.ts` — типы и демонстрационные данные.
- `shared/use-demo.ts` — состояние прототипа в `localStorage`.
- `app.css`, `tailwind.config.json`, `styles.tsx` — оформление.

Подробности архитектуры и ограничений — в `.CHATIUM-LLM.md`.

## Как это запускается

Это воркспейс аккаунта Chatium, а не самостоятельный Node.js-сервер. Chatium
собирает и публикует его после `git push` в ветку `main`; отдельная сборка,
`npm run dev` или локальный сервер не нужны.

Файлы можно положить обратно в корень репозитория аккаунта (папкой `yasna/`) и
опубликовать обычным пушем. Проверка типов:

```sh
chatium typecheck yasna
```

## Демо-данные

Данные вымышленные. Изменения сохраняются в браузере в
`localStorage["yasna.demo.v2"]`, сброс — ссылка «Сбросить демо-данные» в левом
меню. Чеки — реальные файлы в защищённом FileService.

## Ограничения

Нет бэкенда, авторизации и кабинета родителя; оплата демонстрационная. Маршрут
выдачи чека пока не проверяет роль пользователя. Подробнее — в
`.CHATIUM-LLM.md`.
