## Пределы проверки

HTTP-ответы ЮKassa подменены в интеграционных тестах; PostgreSQL настоящая. Проверка через публичный HTTPS webhook и тестовый магазин заказчика не проводилась без реквизитов. Работа пользовательского интерфейса не проверялась: фронтенд ещё не реализован. Автоматический cron/таймер резервного копирования на сервере заказчика не устанавливался.

Инструкции повторения тестов и эксплуатации: [backend/README.md](../backend/README.md).
